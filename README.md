# Phoenix — หน้าเว็บบน GitHub Pages

หน้าเว็บชุดเดียวกับในระบบ Apps Script ระบบหลังบ้าน (Google Sheets / Apps Script) ยังทำงานที่เดิม
หน้าเว็บนี้ส่งคำสั่งไปที่ลิงก์ `/exec` ที่ตั้งไว้ใน `config.js`

> repo นี้เก็บเฉพาะไฟล์หน้าเว็บ ห้ามอัปโหลดไฟล์ `.gs` ข้อมูลบุคคล หรือรหัสผ่านใด ๆ (repo เป็นสาธารณะ)

## ไฟล์ใน repo

| ไฟล์ | หน้าที่ | แก้บ่อยไหม |
|---|---|---|
| `Index.html` `Styles.html` `App.html` `Portal.html` `AttReport.html` | หน้าเว็บ (ชุดเดียวกับใน Apps Script) | ทุกครั้งที่มีการแก้หน้าเว็บ |
| `config.js` | ลิงก์ `/exec` ของระบบ | ครั้งเดียว |
| `tools/build.py` | รวม 5 ไฟล์เป็นหน้าเดียว | ไม่ต้องแก้ |
| `.github/workflows/pages.yml` | ให้ GitHub สร้างและเผยแพร่หน้าเว็บอัตโนมัติ | ไม่ต้องแก้ |

## ตั้งค่าครั้งแรก

1. **Apps Script**
   - สร้างไฟล์ `16_Http.gs` แล้ววางโค้ด และอัปเดต `01_Config` `04_Api` `05_Web` และไฟล์ HTML ทั้ง 5 ไฟล์
   - Deploy › **Manage deployments** › ✏️ แก้ไข deployment เดิม › Version: **New version** › Deploy
   - ตรวจว่า *Execute as* = **Me** และ *Who has access* = **Anyone** (ถ้าเป็น "Anyone with Google account" หน้าเว็บบน GitHub จะเชื่อมต่อไม่ได้)
   - คัดลอกลิงก์ที่ลงท้ายด้วย `/exec`
2. **สร้าง repo** บน GitHub แบบ **Public** แล้วอัปโหลดไฟล์ทั้งหมดในชุดนี้ (รวมโฟลเดอร์ `.github` และ `tools`)
   - ถ้าลากวางบนเว็บแล้วโฟลเดอร์ `.github` ไม่ขึ้น ให้กด *Add file › Create new file* แล้วพิมพ์ชื่อ `.github/workflows/pages.yml` และวางเนื้อหาไฟล์
3. แก้ `config.js` ใส่ลิงก์ `/exec` แทน `XXXX`
4. Settings › **Pages** › Source: **GitHub Actions**
5. แท็บ **Actions** › รอให้ "เผยแพร่หน้าเว็บ Phoenix" เป็นเครื่องหมายถูกสีเขียว (ประมาณ 1 นาที) › ได้ลิงก์ `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/`
6. เปิดลิงก์นั้น เข้าสู่ระบบด้วยบัญชีฝ่ายเลขานุการโครงการ › หน้า **ตั้งค่า** › หัวข้อ *ลิงก์ระบบสำหรับ QR และอีเมล* › กด **ใช้ลิงก์ของหน้านี้** › **บันทึกการตั้งค่า**
   - จากนี้ QR หน้าห้อง QR ลงเวลารายบุคคล และปุ่มในอีเมลจะเปิดหน้าเว็บบน GitHub
   - QR หน้าห้องที่พิมพ์ไว้ก่อนหน้า ต้องพิมพ์ใหม่
7. แจ้งผู้ใช้ให้ใช้ลิงก์ใหม่ และ**เข้าสู่ระบบอีกครั้งหนึ่ง** (เว็บใหม่จำการเข้าสู่ระบบแยกจากเว็บเดิม) ลิงก์ `/exec` เดิมยังใช้ได้ตามปกติ

## ทุกครั้งที่แก้หน้าเว็บ

1. วางไฟล์ HTML ที่แก้แล้วใน Apps Script และ Deploy แบบ **แก้ไข deployment เดิม › New version** (ห้ามกด *New deployment* — ลิงก์ `/exec` จะเปลี่ยน และต้องแก้ `config.js` ใหม่)
2. ใน GitHub กด *Add file › Upload files* อัปโหลดไฟล์ HTML ที่แก้ (ชื่อเดิม ทับไฟล์เดิม) › Commit
3. รอแท็บ Actions เป็นสีเขียว › เปิดหน้าเว็บแล้วกดรีเฟรช

ถ้าแก้เฉพาะไฟล์ `.gs` ไม่ต้องแตะ GitHub — แค่ Deploy แบบแก้ไข deployment เดิม

## เมื่อมีปัญหา

| อาการ | สาเหตุที่พบบ่อย |
|---|---|
| Actions เป็นสีแดง | เปิดดู log — ข้อความจะบอกว่าขาดไฟล์ไหน หรือ App.html ยังเป็นเวอร์ชันเก่า |
| "ยังไม่ได้ตั้งค่าลิงก์ระบบ" | `config.js` ยังไม่ได้ใส่ลิงก์ `/exec` |
| "เซิร์ฟเวอร์ตอบกลับไม่ถูกต้อง" | Deploy ไม่ได้ตั้ง *Anyone* หรือยังไม่ได้สร้าง `16_Http.gs` / ยังไม่ได้ Deploy เวอร์ชันใหม่ |
| "ไม่รู้จักคำสั่ง api…" | ไฟล์ `.gs` ใน Apps Script ไม่ครบ หรือยังไม่ได้ Deploy เวอร์ชันใหม่ |
| แก้แล้วหน้าเว็บยังเหมือนเดิม | รอ Actions เสร็จ แล้วรีเฟรชแบบล้างแคช |
